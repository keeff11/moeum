셀러 심사 화면

아직 배포 전입니다. 이 문구가 보이면 기본인증은 통과한 것입니다.

화면이 들어갈 자리는 src/main/resources/static/admin/ 입니다. API 와 같은 출처라 fetch('/admin/sellers') 처럼 상대경로로 부르면 됩니다 — CORS 설정도 프리플라이트도 없습니다.

쓸 수 있는 API 셋:

  • GET /admin/sellers?status=PENDING&page=0&size=20
  • POST /admin/sellers/{sellerId}/approve
  • POST /admin/sellers/{sellerId}/reject
